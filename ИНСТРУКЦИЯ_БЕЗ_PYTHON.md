# Как получить и установить Audiobook QC без Python

## Что готово сейчас

В этой папке — исходный проект и конфигурация автоматической сборки. **Здесь ещё нет готового `AudiobookQC.exe` или `.dmg`.** Для сборки нужен запуск GitHub Actions, поскольку собирать Windows- и macOS-программы корректно следует на соответствующих операционных системах. Как только сборка пройдёт, end-user ставит программу без Python, командной строки и редактора кода.

## А. Как один раз получить готовые программы через GitHub

1. Войдите в https://github.com/ (или зарегистрируйтесь).
2. Создайте репозиторий `AudiobookQC` кнопкой **New repository**. Выберите **Private** для исходников, если не хотите их публиковать. Для публичных репозиториев стандартные GitHub Actions обычно бесплатны; для частных действуют включённые лимиты и возможны расходы. Не загружайте никакие настоящие аудиокниги и рукописи.
3. Загрузите **СОДЕРЖИМОЕ** папки `AudiobookQC_v0.2.1_без_Python_сборка` в корень репозитория, сохранив структуру папок (`.github/workflows/build.yml`, `src/`, `web/`, `tests/`, `scripts/`, `run.py`, `requirements.txt`). Проще через GitHub Desktop: File → New repository → скопировать содержимое проекта внутрь созданной папки → Commit → Publish repository. Либо в GitHub открыть `Add file → Upload files` и перетащить содержимое, проверив, что папки и вложенность сохранены.
4. Откройте вкладку **Actions** созданного репозитория. Если GitHub предложит разрешить workflows, разрешите после проверки кода. Выберите **Assemble portable Windows and Mac apps** → **Run workflow** → ветка `main` → **Run workflow**. При пуше на `main` сборка может уже запуститься автоматически.
5. Откройте результат последнего запуска. Дождитесь **зелёных галочек всех трёх сборок**. Красная отметка означает, что бинарники не прошли сборку или тест — не устанавливайте их как готовый релиз, откройте журнал ошибки.
6. Внизу страницы запуска в разделе **Artifacts** скачайте нужный архив: `AudiobookQC-Windows-x64`, `AudiobookQC-Mac-Intel` или `AudiobookQC-Mac-Apple-Silicon`. GitHub может сначала скачать внешний ZIP, внутри которого будет ZIP программы для Windows или DMG для Mac.

## Б. Windows 10/11 x64: установка готовой версии

1. Скачайте артефакт `AudiobookQC-Windows-x64` **после успешной сборки**.
2. Распакуйте полученный ZIP и вложенный `AudiobookQC-Windows-x64.zip` при его наличии. **Не запускайте программу внутри ZIP**.
3. Переместите получившуюся папку `AudiobookQC` в удобное место, например `Документы\Программы\AudiobookQC`.
4. Откройте папку и дважды щёлкните `AudiobookQC.exe`. Не переносите один `.exe` отдельно: ему необходимы лежащие рядом папки с библиотеками.
5. Откроется страница локального приложения в браузере. В первый раз при проверке нужно скачать модель распознавания речи через интернет. После этого можно работать без интернета.
6. Чтобы завершить работу, нажмите внутри интерфейса кнопку выхода.

При предупреждении «неизвестный издатель»: это ожидаемо для новой неподписанной программы, но **не доказывает безопасность**. Запускайте только сборку из собственного проверенного репозитория. Не отключайте SmartScreen или антивирус целиком. Если политика безопасности Windows не позволяет запускать приложение, лучше обеспечить цифровую подпись выпуска.

## В. MacBook: установка готовой версии

1. На Mac выберите меню **Apple → Об этом Mac** и посмотрите «Чип»/«Процессор». Если написано Apple M1/M2/M3/M4/M5 — нужен `AudiobookQC-Mac-Apple-Silicon`. Если Intel — `AudiobookQC-Mac-Intel`.
2. Скачайте соответствующий артефакт после зелёного результата сборки, распакуйте внешний ZIP и откройте вложенный `.dmg`.
3. Перетащите `AudiobookQC.app` в **Программы (Applications)** (можно также скопировать вручную из смонтированного образа).
4. Откройте приложение из «Программ». Если macOS пишет, что не может проверить разработчика, только если вы доверяете собранному вами приложению, откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть (Open Anyway)**. Если кнопки нет или macOS сообщает о повреждении приложения, не выключайте защиту; требуется разбирательство с подписью/сборкой.
5. При старте откроется интерфейс в браузере. При первом использовании модели нужен интернет. Для закрытия нажмите кнопку выхода внутри приложения.

## Г. Где файлы и отчёты

Приложение сохраняет аудиокопии, промежуточные части и отчёты локально:
- Windows: `%LOCALAPPDATA%\AudiobookQC`
- macOS: `~/Library/Application Support/AudiobookQC`

При проверке шестичасовой книги выберите интервал отчёта 20 минут: готовая часть скачивается через интерфейс независимо от остальных; после окончания будет общий DOCX. Нужны запас свободного места и возможность не отправлять компьютер в сон на долгой проверке.

## Что остаётся неподтверждённым

Сборка выполняется на GitHub, **этот ZIP сам по себе не является установщиком**. До реального запуска CI не подтверждено, что бинарные файлы собираются без ошибок. Даже после успешного smoke-test необходимо проверить на реальных Windows и Mac качество работы модели с многочасовыми русскими записями и соответствующей рукописью.
