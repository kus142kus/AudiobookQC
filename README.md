# Audiobook QC 0.6 — локальный корректор аудиокниг

> **Статус: исходный код и автоматические тесты; НЕ протестированный выпуск для конечных пользователей.**
> Обновление не заменяет опубликованную версию 0.2.1 и не является готовым `.exe` / `.dmg`.

## Назначение

Автоматически сравнивает озвучку с текстом книги и составляет Word-отчёты о **кандидатах** на реальные оговорки, пропуски и дубли. Работает в отдельном настольном окне (Tk), без браузера и локального HTTP-сервера. После установки **обеих заранее включённых моделей** проверка не требует интернета и не отправляет файлы на сервер. Платных API нет.

### Два независимых распознавателя

- **faster-whisper medium** — первичная запись речи с таймкодами.
- **GigaAM v3 E2E CTC** — повторное распознавание коротких (до 23 с) подозрительных мест. Используется реальное поле `TranscriptionResult.text` из официального API GigaAM.

В краткий DOCX попадают только кандидаты, дополнительно поддержанные двумя моделями (или отдельно обнаруженный технический дефект). Неоднозначные результаты остаются в полном списке в приложении и JSON проекта. Согласие моделей **не доказывает** ошибки диктора; оба распознавателя способны ошибаться одновременно.

### Поддержка многочасовых записей

- MP3/WAV/M4A/FLAC/AAC/OGG/MP4; рукопись DOCX/TXT.
- Поддерживаемая длительность файла в коде: до 48 часов, но полная производительность не измерена.
- Аудио обрабатывается фрагментами по 2 минуты с перекрытием границ.
- Отчёты по частям 5/10/20/30/60 минут появляются **сразу после обработки соответствующей части**; итоговый Word — в конце.
- Контрольные точки на диске; пауза и возобновление анализа.
- Прослушивание внутри окна с ползунком и перемещением ±10 с.

### Ограничения

- GigaAM повторно проверяет только ограниченное количество кандидатных ошибок на часть (по умолчанию 18). Это снижает нагрузку, но может уменьшить полноту выявления оговорок.
- Нет подтверждённого распознавания ударений, всех посторонних звуков и сложных удалённых самопоправок.
- Нет оценки точности на реальном аудио из пользовательского примера `Часть_001.docx`: MP3 и исходная рукопись к этому отчёту не были предоставлены.
- Все модели сейчас работают на **CPU**. MLX/MPS-оптимизация для Mac M4 пока не подключена; скорость на шестичасовом файле неизвестна.
- Нет подтверждённых нативных сборок под Windows и macOS. Intel Mac пока **не поддержан двухмодельной сборкой** из-за отсутствия современных стандартных PyTorch x86_64 macOS-пакетов.
- Для 8 ГБ RAM на Mac необходимо измерить пиковое потребление памяти. Большая офлайн-сборка может занимать несколько гигабайт диска.

## Что исправлено после 0.5

1. Реальная GigaAM возвращает `TranscriptionResult`, а не строку: интеграция исправлена и покрыта отдельным регрессионным тестом.
2. Если в коротком отрывке встречаются и версия рукописи, и версия Whisper, результат остаётся спорным.
3. Для одиночного слова требуется подтверждение соседними словами; случайное совпадение где-то в 23-секундном отрывке больше не повышает приоритет.
4. Подтверждение дубля требует совпадения повторённой фразы с самим кандидатом, а не с другим повтором в том же отрывке.
5. GigaAM больше не зависит от внешней команды `ffmpeg`: подготовленный WAV читается непосредственно, без консольных вспышек Windows.
6. MD5 большой модели теперь проверяется по блокам, не загружая весь файл в память только ради хеша.
7. Добавлены smoke-тест реального ответа GigaAM и сборочная матрица для Windows x64 / Mac Apple Silicon (M1–M5, включая M4).

## Разработка и сборка

Сборка должна выполняться **на целевой ОС**, для этого подготовлен `.github/workflows/build.yml`. В процессе сборки устанавливается Python, загружаются обе модели и проверяются их файлы; в конечном приложении Python и модели включены в дистрибутив.

```bash
python -m pip install -r requirements-build.txt
python scripts/get_offline_model.py
python -m unittest discover -s tests -v
python run.py
```

Для проверки кода без больших моделей достаточно `python -m unittest discover -s tests -v` при установленных базовых библиотеках. Для реальной проверки исполняемого файла GitHub Actions запускает `--self-test` (включая GigaAM `.transcribe()` на PCM WAV) и `--smoke-gui`.

**Именно эти две платформы участвуют в сборке:** Windows x64 и macOS Apple Silicon. Для Mac Intel сейчас не следует обещать готовый установщик.

## Место хранения данных

- Windows: `%LOCALAPPDATA%/AudiobookQC`
- macOS: `~/Library/Application Support/AudiobookQC`

Если используешь ранее опубликованную 0.2.1, не заменяй работающую программу новой тестовой веткой: старые промежуточные результаты были созданы другой моделью. Для настоящего сравнения нужен новый проект и отдельная копия исходных аудио.

## Лицензии и публикация

Исходный код GigaAM и faster-whisper распространяется с собственными лицензиями. До публичной раздачи установщиков нужно проверить права на поставку весов моделей, FFmpeg, Torch/Torchaudio и включить соответствующие уведомления. Наличие публичного репозитория не делает все связанные компоненты автоматически свободными от лицензий.

**Текущие автоматические тесты подтверждают корректность алгоритмической логики на контролируемых случаях, но не измеряют качество распознавания на настоящей озвучке.**
