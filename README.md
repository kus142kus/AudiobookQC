# Audiobook QC 0.2.1 — подготовка сборок без Python для пользователя

**Это исходники и автоматическая сборка, а не уже готовые .exe / .dmg.** Чтобы получить бинарники, GitHub Actions должен выполнить `.github/workflows/build.yml` на Windows и двух архитектурах Mac. В этом окружении собрать и проверить эти платформенные версии невозможно.

Для конечных пользователей **не требуется отдельная установка Python**: PyInstaller пакует встроенную среду выполнения и библиотеки. Первая установка модели для распознавания требует интернета, далее обработка локальная. Сохраняются функции 0.2: разделение длинных аудио, отдельные DOCX-отчёты до завершения всей книги, общий DOCX и CSV, пауза / продолжение, отметки исправлений, локальная работа.

Сборка включает проверку исходников и **новый smoke-test именно собранного приложения**, включая FFmpeg, импорты Whisper/av/tokenizers, HTML и API. Она не доказывает качество распознавания на реальных записях.

**Начните с файла `ИНСТРУКЦИЯ_БЕЗ_PYTHON.md`.**

Не загружайте личные MP3 и рукописи в публичный GitHub-репозиторий. Они не нужны для сборки и не включены в архив.
