# Audiobook QC — локальная проверка качества озвучки аудиокниг

**Audiobook QC** — бесплатный экспериментальный инструмент для дикторов, авторов и студий озвучки. Он сопоставляет записанную аудиокнигу с исходным текстом и формирует список **предполагаемых** ошибок с таймкодами, чтобы сокращать время ручной проверки.

> **Статус: beta (v0.2.1).** Проект находится в разработке. Автоматические тесты и сборки Windows/macOS не подтверждают точность поиска ошибок в реальных аудиокнигах. Не используйте результаты как единственный источник контроля качества.

## Возможности

- Сверка записи с рукописью и обнаружение возможных замен слов, пропусков и расхождений.
- Поиск некоторых повторов, дублей и самопоправок; сложные повторы могут пропускаться.
- Временные метки и прослушивание подозрительного фрагмента.
- Отбор существенных замечаний для Word-отчёта и полный журнал в CSV.
- Проверка длинных записей по блокам с сохранением прогресса и продолжением после остановки.
- **Промежуточный DOCX после каждой готовой части:** не нужно дожидаться конца многочасового анализа.
- Общий DOCX по завершении книги; скачивание ZIP готовых промежуточных отчётов.
- Отметки «исправлено» и «не ошибка»; локальный интерфейс в браузере.
- Экспериментальное предупреждение о выраженной перегрузке сигнала (clipping).

**Пока не реализовано надёжно:** поиск кашля, стуков и других посторонних звуков, проверка ударений и интонации, полное обнаружение всех сложных повторов. Возможны ошибки распознавания, неточные таймкоды и ложные предупреждения.

## Скачать и установить

Перейдите в **[Releases](https://github.com/kus142kus/AudiobookQC/releases)** и выберите предварительный выпуск (когда он опубликован). **Скачивайте файлы из Assets, не `Source code (zip)`: в исходном коде нет готового установщика.**

| Платформа | Файл для скачивания | Как установить |
|---|---|---|
| Windows 10/11, x64 | `AudiobookQC-Windows-x64.zip` | Распаковать архив целиком и запустить `AudiobookQC.exe` из папки `AudiobookQC` |
| macOS, Apple Silicon (M1/M2/M3/M4/M5) | `AudiobookQC-Mac-Apple-Silicon.dmg` | Открыть DMG, переместить `AudiobookQC.app` в «Программы» |
| macOS, Intel x64 | `AudiobookQC-Mac-Intel.dmg` | Открыть DMG, переместить приложение в «Программы» |

**Python отдельно устанавливать не нужно.** При первом использовании модели распознавания необходим интернет для её скачивания. После этого анализ выполняется локально. Из-за отсутствия цифровой подписи Windows/macOS могут предупреждать о неизвестном издателе; устанавливайте только сборки из источника, которому доверяете. Не отключайте системную защиту целиком.

Сборки для Windows ARM, Linux и старых версий macOS **пока не заявлены**. Прохождение автоматической сборки для Intel/Apple Silicon не гарантирует работу на любой версии macOS.

## Использование

1. Запустите Audiobook QC; интерфейс откроется в локальном браузере.
2. Выберите **аудиофайл** и соответствующий **текст книги**.
3. Настройте длительность частей отчёта (например, 20 минут) и запустите проверку.
4. По мере готовности скачивайте отдельные DOCX. При необходимости остановите и продолжите проверку.
5. Прослушайте отмеченные места, отметьте ложные предупреждения и получите итоговый DOCX/CSV.

**Поддерживаемые форматы ввода:** аудио MP3, WAV, M4A, FLAC, AAC, OGG, MP4; рукопись DOCX или TXT. Возможность прочитать конкретный файл зависит также от его кодека и исправности.

Длительные записи, в том числе 6+ часов, обрабатываются по частям. Это архитектурная возможность, а не обещание скорости. Время работы зависит от компьютера и модели распознавания. Для больших записей обеспечьте достаточно места на диске и отключите автоматический сон на время анализа.

## Конфиденциальность

Озвучка, исходная рукопись, промежуточные данные и отчёты хранятся локально на устройстве. Платные облачные API для проверки не требуются. Интернет используется при первоначальной установке модели и скачивании зависимостей при сборке.

**Не загружайте частные аудиозаписи и защищённые авторским правом рукописи в Issues или публичный репозиторий.** Для сообщения об ошибке лучше использовать обезличенный журнал и короткий тестовый фрагмент, на который у вас есть права.

## English

**Audiobook QC** is an experimental, local-first audiobook proofreading assistant for narrators and voice-over studios. It compares recorded speech with a supplied manuscript, flags **possible** word substitutions, omissions and repeated takes, and creates time-coded DOCX reports. Long recordings are processed in chunks, and completed sections can be exported **before the entire book finishes**.

- Windows x64, macOS Intel and macOS Apple Silicon build targets; no separate Python installation required for bundled apps.
- Audio: MP3/WAV/M4A/FLAC/AAC/OGG/MP4. Manuscript: DOCX/TXT.
- Offline analysis after the speech model has been downloaded; no paid cloud API required.
- **Beta software:** detection accuracy is not validated on a representative audiobook dataset. Accent/pronunciation, background-noise and complex retake detection are not reliable or complete.

See the [Releases page](https://github.com/kus142kus/AudiobookQC/releases) for downloadable packages when published. Please review every flagged passage by listening before making an edit.
