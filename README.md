# Audiobook QC — офлайн-проверка озвучки аудиокниг

**Open-source desktop app (0.9.1 beta / исходники-кандидат для будущей 1.0)** for local comparison of audiobook recordings with manuscripts. No subscription, API key, external browser, or cloud transcription required after the complete offline bundle has been installed.

> **Состояние:** исходники и автоматические тесты доступны. Успешная сборка CI **не доказывает** отсутствие ошибок в дикторской записи или совместимость на любом компьютере. Для публичной беты ещё требуются проверка на настоящих Windows/Mac M4, аудит лицензий вложенных моделей и подпись macOS.

📌 [Путь к стабильной версии 1.0 и объективная оценка точности](docs/Путь-к-версии-1.0.md) — это **полный исходный проект с интегрированными доработками**, но пока не готовый выпуск 1.0.

**Удобства для диктора:** в новой проверке можно выбрать папку с **ровно одним аудио и ровно одним DOCX/TXT** — приложение найдёт оба файла; по окончании проверки можно одной кнопкой сохранить итоговый Word. Замечания, отмеченные как «Не ошибка», остаются в журнале, но убираются из корректурного Word.

## Для чего приложение

- Выбираешь аудиозапись (`MP3/WAV/M4A/FLAC`) и исходный текст (`DOCX/TXT`).
- Whisper Medium распознаёт русскую речь; GigaAM v3 выборочно перепроверяет подозрительные места.
- Предполагаемые оговорки, пропуски, повторы и самопоправки сопоставляются с рукописью.
- Отдельно ищутся потенциальные помехи и технические проблемы записи через YAMNet и анализ сигнала (кашель, звонки, щелчки, гул, шипение, возможный клиппинг).
- Получаешь **отдельный Word-отчёт по каждой завершённой части** и итоговый документ; не нужно ждать проверки многочасовой записи.
- В отчёте — **только время от начала всей аудиокниги, по тексту, распознано, что проверить**. Для второй части запись `00:36:00` остаётся `00:36:00`, а не превращается в `00:16:00`. Лишние номера строк, имена файлов, диапазоны и счётчики кандидатов убраны. Таблицы имеют чёткие границы, а звук и небольшие отличия вынесены отдельно.
- Программа работает в отдельном локальном окне на HTML/CSS через WebView/Qt WebEngine; внешний браузер не открывается. Анализ не отправляет записи в облако.

**Важно:** совпадение двух моделей может быть ошибочным; из-за ограниченного числа перепроверок не все оговорки будут найдены. Ударения и интонация проверяются экспериментальными эвристиками, а не достоверным распознаванием русского произношения.

## Установка и поддержка

| Платформа | Текущая готовность |
| --- | --- |
| **Windows 10/11 x64** | Автоматическая офлайн-сборка, требуется реальный пользовательский тест |
| **macOS Apple Silicon** (M1–M5, включая M4) | Отдельный DMG, проверки CI и arm64; требуется тест на M4 и решение по подписи/нотаризации |
| Linux x64 | Экспериментальная совместимость, без подтверждённого пользовательского пакета |
| macOS Intel | Пока без новой двухмодельной сборки |
| Windows ARM64 / Linux ARM64 | Пока не поддерживаются готовыми пакетами |

## Проверка на практике

1. Протестируй 5–10 минут речи и точный отрывок рукописи, в котором заранее знаешь несколько ошибок.
2. Сравни все обнаружения с аудио; отдельно запиши **пропущенные** ошибки и ложные предупреждения.
3. Экспортируй промежуточный Word. Оцени не только оформление, но и полезность замечаний.
4. Затем проверь запись 20–30 минут, паузу/продолжение и отчёты; только потом многочасовой файл.

## Разработка

- Исходники: `src/audiobook_qc/` · Интерфейс: `web/` · Сборки: `.github/workflows/`.
- Тесты: `python -m unittest discover -s tests -v`.
- Первичная диагностика GUI: `python run.py --smoke-gui` (нужны графическая среда и зависимости).
- Контроль выпуска: `scripts/check_release_assets.py`, `scripts/macos_bundle_audit.py`, `THIRD_PARTY_NOTICES.md`.
- Аудиокниги, рукописи и отчёты пользователей **не добавляйте в публичный GitHub**.

## Установка как у обычного пользователя (0.9.1 Beta)

- **Windows x64:** один `AQC-Setup.exe` из GitHub Releases. Установщик сам скачивает проверенную SHA-256 модель Whisper Medium при первоначальной установке. После установки работа полностью офлайн, без Python и браузера. **Не нужно вручную объединять файлы `AQC-Win` и `AQC-Model`.**
- **Mac Apple Silicon / M4:** один `AudiobookQC-Mac.dmg` со всеми моделями. В бета-версии возможно стандартное предупреждение macOS для неподписанных приложений.
- Первичная установка Windows требует подключения к интернету из-за ограничения GitHub Releases (<2 GiB на отдельный файл). Работа установленной программы интернет не использует.

Полная пошаговая инструкция: [Установка-в-общем-доступе.md](docs/Установка-в-общем-доступе.md). Публичное описание бета-релиза: [RELEASE_BETA.md](docs/RELEASE_BETA.md).
