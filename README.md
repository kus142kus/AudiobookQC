# Audiobook QC 0.7 — автономный контроль качества аудиокниг

**Состояние: исходники и автоматические тесты. Готовые EXE/DMG должны быть собраны и проверены на Windows/Mac в GitHub Actions. Реальная точность моделей на вашей аудиокниге пока не измерена.**

Приложение с отдельным современным HTML/CSS-окном (pywebview; без браузера, HTTP-сервера и интернета во время проверки). Сравнивает русскую аудиокнигу с DOCX/TXT, даёт таймкоды, прослушивание, отметки и **промежуточные Word-отчёты после каждой завершённой части**. Поддерживает длительные записи и продолжение после остановки.

## Что анализируется

| Направление | Метод | Как интерпретировать |
|---|---|---|
| Оговорки, пропуски, дубли | Whisper Medium + выборочная независимая GigaAM-v3 | Только кандидаты; требуется проверка на слух |
| Имена и термины | Сопоставление с рукописью, эвристика имён, пользовательский словарь | Другая нейросеть должна подтвердить важное расхождение |
| Кашель, стуки, звонки, клавиатура и др. | Локальная YAMNet ONNX, обученная на AudioSet | События вероятностные; особенно рядом с голосом возможны ошибки |
| Клиппинг | Накопление отсчётов у цифровой границы | Более объективное техническое предупреждение |
| Щелчки | Очень короткие высокоамплитудные импульсы | Могут быть взрывными согласными; только прослушивание |
| Сетевой гул | Выраженная линия 50/60 Гц в тихих окнах | Возможное загрязнение звука |
| Шипение/фон | Высокочастотная энергия в тихих окнах | Грубая эвристика; не различает все шумы |
| Неправильное ударение | **Экспериментальный** акустический ритмический признак для слов с вручную помеченным ударением | **НЕ** распознавание реального ударения; слабое предупреждение |
| Интонация | **Экспериментальный** признак сильного падения тона в вопросительных предложениях | В русском падение тона допустимо; это не доказательство ошибки |

Без обученной русскоязычной фонемной модели и эталонного чтения нельзя надёжно распознавать все ударения и оценивать «правильность» выразительной интонации. Поэтому такие находки **не попадают в раздел подтверждённых ошибок**; они показываются только для прослушивания.

### Словарь

В новой проверке есть необязательное поле «Имена, термины и ударения». Вводите по одному термину на строке: `княги́ня`, `Потёмкин`, `цивилизационный`. Для ударений ставьте Unicode-знак ударения после нужной гласной: `княги́ня` (можно и `княги+ня`). Если акцент не указан, термин защищён для сверки, но акустическое ударение не проверяется.

### Порядок работы

1. Выбрать MP3/WAV/FLAC/M4A и рукопись DOCX/TXT.
2. При необходимости внести важные имена и термины со знаками ударения.
3. Выбрать 5–60 минут на отдельный Word-отчёт и нажать «Начать проверку».
4. По завершении каждой части открыть или сохранить **Часть_001.docx**, затем следующие части, пока обработка продолжается.
5. Прослушать кандидатов, отклонить ложные, отметить исправленные.
6. После окончания найти `Полный_отчёт.docx` в папке проекта.

### Приватность и платформы

При наличии локальных весов Whisper, GigaAM и YAMNet все проверки выполняются без внешних запросов. Модели скачиваются **только на сборочном компьютере** GitHub Actions. Рабочие данные не загружаются на сторонние серверы. Поддерживаемые в CI целевые платформы: Windows x64 и macOS Apple Silicon (включая M4). Intel Mac, Linux и Windows ARM64 пока не имеют подтверждённых сборок. На Windows 10 может потребоваться системный WebView2 Runtime; он обычно предустановлен в Windows 11.

### Для разработчиков

- Основной код: `src/audiobook_qc/`; интерфейс: `web/`.
- `scripts/preflight_source.py` ловит отсутствующие функции и несогласованность интерфейса с движком, **до** загрузки моделей.
- `python -m unittest discover -s tests -v` — синтетические и интеграционные тесты.
- `scripts/get_offline_model.py` — загрузка Whisper и GigaAM при сборке; `scripts/get_event_model.py` — загрузка YAMNet ONNX.
- `.github/workflows/build.yml` — загрузка моделей, целостность, реальное выполнение inference, упаковка и smoke-test EXE / macOS app.
- `scripts/benchmark.py PATH_TO_PROJECT labels.csv` — точность/полнота относительно ручной разметки, `labels.csv`: `start,end,kind`, секунды.

### Ограничения качества

Whisper Medium и GigaAM по-прежнему способны ошибаться на редких фамилиях и терминах; две согласные нейросети не гарантируют правильного ответа. На часть установлен лимит 18 независимых перепроверок текстовых расхождений. YAMNet не специализируется на аудиокнигах и не заменяет ручной контроль. Сверхдлинные записи по частям тестировались с моделируемыми результатами, но скорость и точность реальной шестичасовой записи не доказаны.
