# AudiobookQC — проверка озвучки аудиокниг

**Бесплатная локальная программа для дикторов и редакторов.** Сравнивает запись с оригинальным текстом, ищет предполагаемые оговорки, пропущенные или заменённые слова, повторы и возможные дефекты звука. Создаёт Word-отчёт с таймкодами.

## Как работает

1. Выбери **аудиофайл** (`MP3`, `WAV` и другие поддерживаемые форматы) и соответствующий **текст** (`DOCX` или `TXT`).
2. Нажми **«Начать проверку»**. Whisper распознаёт речь, GigaAM перепроверяет подозрительные фрагменты. При длительных записях результаты сохраняются по частям.
3. Прослушай замечания и сохрани **Word-отчёт** с таймкодами и предполагаемыми исправлениями.

Для первого теста хватит 5–10 минут записи. После установки обработка выполняется локально; установщик Windows при первой установке загружает модель из соответствующего выпуска.

## Возможности

- Поиск предполагаемых замен, пропусков, повторов, включая изменения смысла и отрицания.
- Приоритет существенным замечаниям; сомнительные случаи показываются отдельно.
- Отметки **«Исправлено»** и **«Не ошибка»**, воспроизведение подозрительного места.
- Отдельные предупреждения о возможных звуковых артефактах (не окончательный диагноз).
- Промежуточные и итоговый Word-отчёты, возобновление длинных проверок.
- Без оплаты подписки и облачной отправки рукописей и записей.

## Установка и помощь

- **Mac:** скачать `.dmg`, открыть, перетащить AudiobookQC в «Программы», запустить. Если macOS блокирует неподписанное приложение, следовать системной инструкции *«Конфиденциальность и безопасность»*; не отключать защиту целиком.
- **Windows:** скачать `AQC-Setup.exe`, открыть, следовать шагам установки. При первом запуске установщика нужен интернет для моделей.
- **Linux:** скачать соответствующий `PREVIEW.tar.gz`, распаковать и запустить исполняемый файл. Это тестовый пакет, возможна потребность в системных библиотеках.
