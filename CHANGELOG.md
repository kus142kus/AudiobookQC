# Изменения Audiobook QC

## 0.9 — таблицы, читаемость, аудит ОС (кандидат)

- Восстановлены заметные границы таблиц Word, строгие заголовки, читаемые колонки и чередование строк.
- Шапки таблиц повторяются на каждой странице, строки не разрываются внутри, длинные ASR-фрагменты ограничиваются по длине.
- Звуковые предупреждения, включая клиппинг, не попадают повторно в таблицу ошибок чтения.
- Проверен рендер реального короткого примера и стресс-отчёта на 12 страниц.
- Ранняя проверка фактической архитектуры CI: Windows x64 и Mac arm64 (M4).
- Проверка исполняемых файлов внутри macOS frameworks расширена.
- Отдельный подробный аудит остальных ОС, честная матрица подтверждений.
- Прежние 0.8 на GitHub пользователем ещё не загружены — выпуск содержит полный проект.

# История изменений

## 0.8.0 Beta — редакторский отчёт и подготовка публикации

- Полностью переделан DOCX: краткая сводка, читабельные карточки с таймкодами, статусами и полем для отметок.
- Возможные редакционные варианты (например, «мной/мною») отделены от важных расхождений.
- Звуковые предположения отделены от ошибок чтения, и не объявляются доказанным браком.
- Добавлена проверка размера (<2 ГиБ), целостности ZIP и SHA256 перед релизом.
- Для macOS arm64 добавлен аудит Mach-O бинарников и проверка DMG.
- Добавлен экспериментальный (без моделей) Linux x64 GUI smoke workflow; другие архитектуры отмечены как неподтверждённые.
- Добавлены MIT-лицензия собственных исходников, реестр третьих сторон, инструкции для MacBook M4 и подготовка публикации.
- **Не заявляется:** готовая публичная stable-версия, notarized Mac, подтверждённая точность на реальных аудиокнигах.


## 0.5 — независимое подтверждение двумя ASR

- Подключён GigaAM v3 E2E CTC к реальному обработчику частей в `worker.py`.
- Whisper — первичное распознавание, GigaAM — перепроверка при расхождении с текстом.
- Клипы GigaAM ограничены 23 секундами из-за требований модели.
- Разделены «подтверждённый кандидат» и «недостоверная машинная гипотеза».
- Запрет тихого возврата к одной модели: отсутствующие веса GigaAM — понятная ошибка, а не фиктивная верификация.
- Word-экспорт и основной экран для новых книг показывают только действительно перепроверенные текстовые кандидаты. Остальное — в расширенном списке.
- Дополнительно перепроверяются некоторые короткие смысловые подмены, не только длинные фразы.
- Сохранены нативный интерфейс, отдельные Word по частям, контрольные точки и встроенный проигрыватель.
- Добавлены модульные и интеграционные тесты двухмодельного конвейера; реальные модели, платформы и качество озвучки требуют проверки отдельно.
