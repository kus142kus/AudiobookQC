# Участие в разработке / Contributing

Приветствуются исправления багов, тесты на синтетическом или разрешённом к публикации аудио и помощь с поддержкой платформ.

1. Создайте Issue с ОС, архитектурой, версией приложения и воспроизводимыми шагами.
2. Не прикладывайте защищённые авторским правом аудиокниги, рукописи, персональные данные или секреты.
3. Для изменений алгоритма поиска ошибок прикладывайте тест с известным правильным ответом и измерением ложных/пропущенных срабатываний. Не называйте предварительные находки доказанным браком.
4. Для UI/Word изменений приложите до/после скриншот **с вымышленными данными**.
5. Перед Pull Request запускайте `python -m unittest discover -s tests -v` и `python scripts/preflight_source.py`.
6. Для совместимости с Mac M4 требуется успешный arm64 workflow и реальный тест на устройстве; сборка CI не доказывает удобство и скорость на M4.

Английский: Issues and PRs are welcome. Please include reproducible test cases, avoid private manuscripts/audio and document any third-party licence changes.
