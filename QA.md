# Технический аудит Audiobook QC 0.8 Beta — 24.11.2026

## Что проверено здесь

- **114 тестов Python** прошли в рабочем контейнере без весов моделей; включая отчёты Word, реестр замечаний, отсутствие ложной классификации звука, потоковые отчёты по 18 частям, контроль GitHub release size и ошибки GUI на заглушках.
- `scripts/preflight_source.py`: проверен контракт импорта UI ↔ backend.
- `python -m compileall`: синтаксические ошибки Python не найдены.
- GitHub Actions YAML (`build.yml`, `compatibility.yml`) и Issue Form YAML: разобраны; все шаги `run`/`uses` заданы.
- Новый образец DOCX с **фактическими находками из предоставленного отчёта**, перестроенный без реального MP3, отрендерен в PNG; страница визуально проверена.
- Проверка checksum/2 GiB ZIP/DMG, аудитор Mach-O архитектуры и инструкции Mac M4 имеют отдельные тесты или этапы CI.

## Чего эта проверка не подтверждает

- Реальный запуск GUI и нейросетей на конкретном Windows / MacBook M4 после **нового** обновления (настоящая сборка и пользовательские тесты ещё не выполнены).
- Работу экспериментального Qt GUI на Linux: добавлен отдельный workflow только для source smoke, не готовая Linux-версия.
- Корректность ударений, интонации и звуковых событий на настоящем аудио, память и скорость на шестичасовых аудиокнигах.
- Подписанный и нотариализованный установщик для Mac.
- Полное соответствие бинарного пакета лицензионным обязательствам третьих сторон. См. THIRD_PARTY_NOTICES.md.

## Контрольные точки перед открытым Release

1. **Windows x64 и Mac arm64** — обе сборки зелёные, GUI и три модели проверены в запакованном приложении.
2. DMG проверен hdiutil, arm64 библиотеки проверены на Mach-O архитектуру.
3. ZIP проходит проверку целостности, файлы **строго меньше 2 GiB** и есть отдельный файл `.sha256` для каждой платформы.
4. Запуск на настоящей Windows и Mac M4 (сообщения о Gatekeeper задокументированы).
5. Оценка точности на ручной разметке настоящего фрагмента (число ошибок, не только процент успешных тестов).
6. Проверка сторонних лицензий и разрешений на публичное распространение моделей.
