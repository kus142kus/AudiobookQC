# Аудит Audiobook QC 0.7

## Конкретная причина последнего сбоя

В GitHub Actions тест `test_webview_shell` падал на `ImportError: cannot import name 'delete_saved_project'`. Это произошло из-за несовместимых версий `desktop_web.py` и `desktop.py`. **Полный `desktop.py` теперь входит в поставляемый исходный ZIP**, а `scripts/preflight_source.py` проверяет символы GUI ↔ backend до скачивания дорогих моделей.

## Проверено в текущем окружении

- Python 3.13: полный импорт исходного пакета и проверка API-интерфейсов — пройдены.
- `unittest discover -s tests`: см. `QA_TESTS.txt` (включая старые тесты).
- Проверка синтаксиса Python через `compileall` — пройдена.
- YAML-файл GitHub Actions читается без ошибок синтаксиса.
- Синтетические PCM: импульс, 50-Гц гул, белый шум, отсутствие ложного клиппинга на чистом тоне — пройдены.
- YAMNet ONNX-интерфейс: тест через заглушку, агрегация соседних окон, таймкоды — пройдены.
- Поддельный проект: двухмодельный worker + YAMNet + сохранение обнаруженных событий в DOCX — пройден.
- Шесть часов: 18 промежуточных DOCX, одна финальная сводка на синтетических результатах — пройден.
- Словарь ударений, выделение специального термина, Word-раздел для кандидатов — пройдены.
- Бенчмарк precision/recall с парным сопоставлением — пройден.

## Что нельзя проверить в этой среде

1. Настоящее распознавание моделей Whisper/GigaAM: бинарные веса в окружении отсутствуют.
2. Настоящая ONNX-модель YAMNet: загрузка с внешнего сервера недоступна в контейнере. В Github Actions добавлен *обязательный* тест реального запуска YAMNet, ошибка сборки не будет скрыта.
3. Память, запуск WebView2/WKWebView, macOS-разрешения и подпись: требуется запуск реальных Windows/Mac артефактов.
4. Точность на голосе диктора: нет размеченной записи. Нельзя утверждать, что найденный кашель, ударение или интонация верны без аудиоподтверждения.

## По новым возможностям

| Модуль | Статус | Ограничение |
|---|---|---|
| Имена и термины | Рабочая защита словарём и сопоставление при наличии расшифровки | Нейросети ошибаются на редких словах |
| Клиппинг | Автоматический PCM-алгоритм | Не все виды нелинейных искажений видны по амплитуде |
| Щелчок | Детектор изолированных пиков | Может сработать на согласных |
| Гул 50/60 Гц | Спектральная проверка пауз | Не ловит весь низкочастотный фон |
| Шипение | Высокочастотная энергия пауз | Может спутать шум с речевыми артефактами |
| Кашель/стуки/звонки | YAMNet AudioSet ONNX, обязательна комплектация в CI | Вероятностная классификация, не специализирована под дикторов |
| Ударения | Экспериментальная энергия приблизительных слогов с пользовательским эталоном | Нет фонемного выравнивания, достоверность низкая |
| Интонация | Экспериментальная фразовая проверка вопросительного конца | Не оценивает актёрскую выразительность; ложные срабатывания неизбежны |

Все сомнительные акустические и просодические события имеют статус `review`, а не «подтверждённая ошибка»; Word отделяет их в специальный раздел.
