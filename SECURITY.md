# Безопасность и приватность

Audiobook QC обрабатывает файлы локально; установочные пакеты должны содержать все необходимые модели. Не загружайте личные аудиозаписи, рукописи или `crash.log` без предварительной проверки содержимого в публичный Issue.

Для конфиденциальных уязвимостей используйте GitHub **Private vulnerability reporting** (если оно включено в настройках репозитория) либо сначала запросите у владельца безопасный канал связи в Issues без подробностей эксплуатации. Не публикуйте ключи, токены, адреса или закрытые файлы.

Стабильных публичных гарантий безопасности или поддержки всех ОС пока нет: это предварительная версия.
