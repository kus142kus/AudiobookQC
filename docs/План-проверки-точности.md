# AudiobookQC: как объективно измерить качество проверки

**Цель:** не просто «программа создала DOCX», а экономия времени диктора при нахождении существенных оговорок.

## Подготовка теста (без публикации рукописей)

Нужны 3 аудиофайла по 5–15 минут с точными отрывками DOCX/TXT. В каждом сохранить список ошибок, подтверждённых самостоятельным прослушиванием. Добавь, где возможно, реальные: **замена слова, пропущенное слово/фраза, лишнее слово, повтор/самопоправка, отрицание «не», число, имя собственное**. Отдельно собери **не-ошибки**: «о/а», «е/я», различия написания/слитности, цифры прописью, паузы и допустимые варианты произношения. Для ударений подготовь отдельные примеры.

## Как оценивать каждый отчёт

1. Запускай анализ с отключённым интернетом, при наличии всех моделей. Убедись, что аудиофайл не покидает компьютер.
2. Для каждого найденного замечания: **верная существенная ошибка / ложная тревога / неуверенно**. Записывай абсолютный таймкод, верный текст, услышанный текст.
3. Отдельно найди в заранее размеченном списке **пропущенные ошибки**. Считай ошибкой, если таймкод отклоняется больше чем на 3–5 секунд либо замечание нельзя найти в записи без долгих поисков.
4. Считай **точность (precision)** = верно найденные существенные ошибки / все выданные существенные замечания. **Полноту (recall)** = верно найденные существенные ошибки / все реальные существенные ошибки теста. При оценке требуется одно-к-одному сопоставить замечания с реальными ошибками: два замечания об одной оговорке считаются дублем, а не двумя успехами.
5. Замерь время автоматической проверки и **реальное время работы диктора**: сколько заняло прослушивание кандидатов, удалось ли исправить запись с первого прохода.

## Минимальный пользовательский сценарий

- 5–10 минут, затем 30 минут, затем 2–6 часов.
- TXT и DOCX с таблицами, MP3/WAV/M4A, русские имена, длинные паузы, пустые фрагменты.
- Частичный DOCX после первой части, пауза/продолжение, отчёт после завершения, перезапуск приложения.
- Проверить, что таймкоды во второй/следующих частях абсолютные, а при неверной модели/тишине появляется понятная ошибка, а не ложное «всё чисто».
- На Mac M4 и Windows отдельно: запуск после установки, работа офлайн и экспорт Word.

**Важно:** по текущей архитектуре проверка ударений носит экспериментальный характер. Нельзя писать «ударение точно неверно», если это не доказано надёжной проверкой произношения/человеком.
