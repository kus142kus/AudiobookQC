# Audiobook QC — как выглядит установка для обычного пользователя

## Windows x64

1. Перейти на страницу Releases: https://github.com/kus142kus/AudiobookQC/releases
2. Скачать **только `AQC-Setup.exe`** (не Source code, не `AQC-Model.zip`).
3. Запустить установщик. Он проверяет, установлен ли Whisper Medium. Если нет — загружает модель с **этого же релиза** по HTTPS, проверяет SHA-256 и извлекает её в папку приложения. Никаких ручных ZIP, Python, консоли или браузера.
4. После проверки установки запустить Audiobook QC с рабочего стола или из меню Пуск. Программа работает без интернета и API. Установщик можно удалить; если модель уже установлена и её контрольная сумма совпадает, повторная установка пропускает её загрузку.

**Ограничение:** на первом запуске установщика интернет обязателен, модель примерно 1,3 ГБ. Если загрузка прервалась или хэш не совпадает, установка не должна считаться успешной. Нужны свободное место под скачивание и распаковку и разрешение Windows на запуск неподписанного приложения. Этот бета-установщик пока не подписан EV/Authenticode — возможен SmartScreen.

## Mac Apple Silicon (включая M4)

1. Из того же Releases скачать **`AudiobookQC-Mac.dmg`**.
2. Открыть DMG и перенести `AudiobookQC.app` в «Программы».
3. Запустить по обычной процедуре macOS. При предупреждении Gatekeeper использовать разрешённый Apple способ открыть неподписанный пакет, только если вы доверяете релизу. Не предлагать отключать Gatekeeper глобально.
4. Протестировать десятиминутную запись и экспорт Word без интернета.

Все модели включены в DMG; ничего отдельно скачивать не нужно.

## Как проверить точно такой же вариант, который будет опубликован

В GitHub Actions откройте workflow **Audiobook QC 0.9 - offline release assets** → **Run workflow** → установите `publish_beta = true` только когда хотите опубликовать prerelease. Workflow сперва тестирует Windows/Mac, затем прикрепляет **готовый `AQC-Setup.exe`, `AQC-Model.zip` и `AudiobookQC-Mac.dmg` непосредственно к GitHub Release**. Только после этого Windows-установщик сможет скачать модель по публичной ссылке.

Для теста зайдите в созданный **Pre-release** и скачайте обычную кнопку `AQC-Setup.exe`: это ровно тот путь, который увидят будущие пользователи. Не скачивайте Artifacts и архивы внутри них. Не открывайте два ZIP и не переносите папки руками.

Публикация — отдельное явное действие. Обычный commit запускает тестовые сборки, но релиз не публикует.
