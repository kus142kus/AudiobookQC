# Установка Audiobook QC: Windows и macOS

**Выпуск 1.0 RC2 — предварительная версия, не стабильный релиз.** Скачивайте файлы исключительно из [GitHub Releases](https://github.com/kus142kus/AudiobookQC/releases). Если RC2 в Releases ещё отсутствует, его публичная публикация не выполнена; не перепутайте с ранним выпуском `v0.2.1-beta.1`.

## Windows 10/11 x64

1. Откройте актуальный предварительный выпуск и скачайте **`AQC-Setup.exe`**. Не выбирайте «Source code», `AQC-Model.zip` или архивы GitHub Actions.
2. Запустите EXE. Из-за отсутствия публичной подписи Windows может показать предупреждение SmartScreen. Запускайте приложение только если доверяете источнику и файлу; не отключайте защиту Windows глобально.
3. На первой установке требуется **интернет**: установщик самостоятельно скачивает `AQC-Model.zip` из **того же релиза**, проверяет SHA-256 и устанавливает модель. **Модель вручную скачивать и объединять с EXE не нужно**.
4. Дождитесь окончания установки. Откройте Audiobook QC в меню «Пуск» либо через созданный ярлык.
5. Для теста отключите интернет и проверьте короткий файл, затем сохраните Word.

Если модель не скачивается, проверьте, что в том же релизе действительно размещён `AQC-Model.zip` и интернет доступен. Если выпуска с моделью нет, установку этого EXE нельзя считать полноценной. Потребуется достаточно свободного места для временного архива и распакованных моделей.

## macOS Apple Silicon (M1–M5, включая M4)

1. На Mac откройте релиз и скачайте **`AudiobookQC-Mac.dmg`**.
2. Откройте DMG и перетащите `AudiobookQC.app` в **Программы / Applications**.
3. Запустите приложение из папки «Программы». В тестовом выпуске возможна блокировка Gatekeeper из-за отсутствия Developer ID и нотариализации. **Не отключайте Gatekeeper**. Если доверяете файлу и проверили источник, следуйте [официальной инструкции Apple](https://support.apple.com/en-us/102445) для конкретного предупреждения; если сомневаетесь — не запускайте.
4. На Mac модели уже находятся **внутри DMG**. Дополнительные ZIP и загрузки моделей не требуются.
5. Проверьте короткий фрагмент аудио и экспорт Word. Реальная работа на M4 пока не считается подтверждённой до такого теста.

**Mac на процессорах Intel не поддерживается этим DMG.**

## Linux и другие ОС

Linux x64 и ARM64 доступны только как **экспериментальные ручные сборки разработчика**. Пользовательских проверенных пакетов и универсального установщика пока нет. Windows ARM64 и macOS Intel также не объявлены поддерживаемыми. Не устанавливайте сборку чужой архитектуры наугад.

## Первый запуск

Подготовьте папку с одним аудиофайлом и соответствующим DOCX/TXT. В программе выберите **«Новая проверка» → «Выбрать папку с двумя файлами»**, задайте интервал отчётов и нажмите **«Начать проверку»**. После каждой готовой части можно сохранить Word; итоговый Word доступен после завершения всей записи. [Полное руководство](Руководство-пользователя.md).

**Соблюдение конфиденциальности:** рабочие записи и рукописи остаются на компьютере пользователя; публичные отчёты об ошибках не должны содержать защищённые материалы.

## Дополнительные архитектуры (экспериментально)

Linux x64 / Linux ARM64, Mac Intel и Windows ARM64 не входят в подтверждённую основную пользовательскую сборку. Для пробных проверок предусмотрен отдельный [сценарий дополнительных платформ](Дополнительные-платформы.md). **Архив `PREVIEW` не равен готовому стабильному установщику.** Для Linux после успешной сборки смотрите [частые вопросы](Частые-вопросы.md), где описано распаковывание tar.gz. Для Windows ARM64 проверяется только x64-эмуляция; Mac Intel может не пройти зависимость GigaAM, в таком случае DMG не создаётся.
