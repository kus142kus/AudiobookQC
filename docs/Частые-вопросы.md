# Частые вопросы об Audiobook QC

Это пользовательское руководство для **1.0 RC2 (предварительной версии)**, а не подтверждение готовности стабильного выпуска.

## Нужна ли регистрация, подписка, Python или GitHub?

Нет. Пользователь устанавливает **приложение из раздела Releases**; исходники и GitHub Actions ему не нужны. После установки проверка рукописи и записи выполняется локально. На Windows установщик при первой установке скачивает архив модели с GitHub и проверяет контрольную сумму; **после установки интернет для анализа не требуется**. Mac Apple Silicon DMG уже содержит модели.

## Какую версию скачивать?

- Windows 10/11 Intel или AMD 64-bit: `AQC-Setup.exe` из **конкретного опубликованного релиза**; отдельный архив `AQC-Model.zip` вручную не нужен.
- Mac с M1/M2/M3/M4/M5: `AudiobookQC-Mac.dmg` из Releases. Для Intel Mac этот DMG не подходит.
- Linux x64 / Linux ARM64: доступны *только экспериментальные артефакты Actions*, если соответствующая ручная сборка действительно прошла. Это не стабильные установщики.
- Windows 11 ARM64: отдельный эксперимент проверяет запуск **x64-установщика через эмуляцию**. Это не нативная версия и не доказательство корректного анализа.
- Mac Intel: отдельный эксперимент пытается собрать приложение с более старым PyTorch и проверяет реальную работу моделей; если зависимость несовместима, артефакта DMG не будет.

## Как запустить первый анализ?

1. Подготовьте **соответствующие друг другу** запись `Фрагмент.mp3` и рукопись `Фрагмент.docx` в одной папке.
2. Откройте **«Новая проверка» → «Выбрать папку с двумя файлами»** или выберите файлы вручную.
3. Выберите время промежуточных отчётов (например, 20 минут) и нажмите **«Начать проверку»**.
4. После готовности части прослушайте замечания, отметьте ложные и сохраните Word. Итоговый Word станет доступен после завершения всех частей.

Для первого теста лучше использовать фрагмент 5–10 минут, где заранее известны несколько оговорок.

## В отчёте есть слова «распознано», «по рукописи», «проверить». Что считать ошибкой?

Это **предположения**, а не окончательный приговор диктору. Особо важны пропуски предложений, лишние повторы, замены слов со сменой смысла, отрицания, имена и числительные. Разницу вроде «мною/мной» можно не считать браком, если допускается свободная редакция текста. При сомнении прослушайте несколько секунд до и после таймкода. Автоматическая проверка способна и **не заметить** настоящую ошибку.

## Проверяет ли ударения?

Ударения, интонация и посторонние звуки отмечаются **экспериментально** и требуют прослушивания. Не следует исправлять запись только на основании одной такой метки.

## Можно ли остановить многочасовую проверку?

Используйте кнопку **«Приостановить»**, дождитесь изменения статуса и затем **«Продолжить»**. Не перемещайте исходные файлы и не удаляйте рабочую папку проекта в процессе анализа. Промежуточные Word-файлы можно сохранять по завершении частей.

## Windows не устанавливается / не загружает модель

Проверьте интернет во время первой установки и наличие **обоих** файлов `AQC-Setup.exe` и `AQC-Model.zip` **в одном выпуске GitHub Releases**. Внешний ZIP от GitHub Actions не является установщиком для пользователя. Предупреждения SmartScreen возможны у неподписанного приложения — сверяйте источник, не отключайте защиту Windows полностью.

## Mac сообщает, что приложение не удаётся открыть

Убедитесь, что у вас Apple Silicon, скачан официальный DMG и приложение перемещено в **Программы**. В тестовом RC могут возникать предупреждения из-за отсутствия подписи Developer ID/нотаризации. Следуйте [официальной инструкции Apple](https://support.apple.com/en-us/102445) только если доверяете приложению. Не отключайте Gatekeeper глобально. Если появляется сообщение о повреждённом приложении, **не пытайтесь обходить его командами из интернета**; сообщите об ошибке.

## Экспериментальный Linux: как попробовать, если сборка зелёная?

Скачайте артефакт `AQC-Linux-x64-PREVIEW` или `AQC-Linux-ARM64-PREVIEW` из соответствующей сборки Actions. Распакуйте внешний ZIP, затем внутренний `tar.gz`:

```bash
tar -xzf AudiobookQC-Linux-x64-PREVIEW.tar.gz
./AudiobookQC/AudiobookQC
```

Для ARM64 замените имя архива на `AudiobookQC-Linux-ARM64-PREVIEW.tar.gz`. Используйте пакет **только на подходящей архитектуре**; для Qt/WebEngine могут потребоваться системные библиотеки. Отсутствие артефакта или красная сборка означает, что готовой Linux-версии ещё нет. Не делайте выводов о совместимости до проверки экспорта Word на реальном Linux.

## Приложение работает только с русским языком?

Проверка построена вокруг русскоязычной озвучки и соответствующих моделей. Качество анализа других языков **не проверено**, поэтому не заявляется поддержка многоязычных аудиокниг.

## Как сообщить об ошибке без публикации книги?

Откройте [GitHub Issues](https://github.com/kus142kus/AudiobookQC/issues) и укажите: версию приложения, ОС и процессор, шаг, на котором возникла ошибка, ожидаемый и фактический результат, обезличенный скриншот. **Не прикладывайте публично защищённую рукопись, голосовую запись, полный Word-отчёт или файлы с личными данными.**
