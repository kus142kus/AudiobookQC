# Audiobook QC — первая проверка на MacBook M4

Версия: предварительная (beta). Вариант: **Mac Apple Silicon (arm64)**. Intel-сборку не использовать.

## Перед передачей

Разработчик проверяет **успешный запуск GitHub Actions на macOS arm64**, наличие `AUDIOBOOK_QC_NATIVE_DESKTOP_OK`, результат `scripts/macos_bundle_audit.py`, проверку DMG (`hdiutil verify`) и отсутствие ошибок `--test-gigaam` / `--test-events`. **Это не заменяет запуск на настоящем M4.**

## Установка

1. Скачайте именно `AudiobookQC-Mac-Apple-Silicon` из проверенного GitHub Release (или Artifacts указанного запуска). Извлеките DMG, если он лежит внутри ZIP артефакта.
2. Откройте DMG, перенесите `AudiobookQC.app` в **Программы / Applications**.
3. В публичной бете приложение может быть **без подписи Developer ID и нотариализации**. macOS может заблокировать первое открытие. Не выключайте Gatekeeper глобально. Если доверяете конкретному скачанному пакету, следуйте штатному пути Apple: *Настройки системы → Конфиденциальность и безопасность → Всё равно открыть* (разрешение появляется после попытки запуска). Если нет уверенности в происхождении файла — не запускайте.
4. Интернет для анализа не нужен. Для первого теста временно выключите Wi‑Fi и убедитесь, что программа действительно запускается.
5. На проверке выберите 3–5 минут записанного аудио и ровно соответствующий документ DOCX/TXT. Проверьте, что не происходит сетевых запросов.
6. Прослушайте по крайней мере 2 замечания и экспортируйте отдельный Word-отчёт по завершившейся части. Пауза/продолжение должны работать.
7. Не начинайте с шестичасовой книги. После короткого теста проведите 20–30-минутный тест и только затем длинную проверку.

## Что прислать разработчику

- Версия macOS и объём оперативной памяти; не нужно присылать серийный номер устройства.
- Продолжительность аудио и сколько времени занял анализ (без записи самого файла, если книга конфиденциальна).
- Скриншот главного экрана и **обезличенную** часть отчёта либо описания проблем.
- При сбое откройте Finder → **Переход → Переход к папке…** (`Cmd+Shift+G`) и вставьте `~/Library/Application Support/AudiobookQC`. В этой папке может находиться `crash.log`. Проверьте на конфиденциальность, прежде чем делиться.

## Известные ограничения

- Несмотря на название «нативное окно», интерфейс реализован на локальном HTML/CSS в системном WebKit; браузер отдельно не открывается.
- Whisper Medium и GigaAM работают на CPU, ускорение Apple MLX пока не реализовано. Скорость на M4 и пиковое использование памяти ещё не измерялись.
- Поиск ударений и интонации экспериментальный; не считать находки доказанными ошибками.
- Подписанный и нотариализованный DMG требует Apple Developer ID и отдельного выпуска; GitHub Actions сам по себе не заменяет подпись.
