# Публикация Audiobook QC в общий доступ — пошагово

Исходный репозиторий уже публичный: https://github.com/kus142kus/AudiobookQC . Это **не** значит, что новая проверенная версия уже опубликована в GitHub Releases.

## Что подготовлено в обновлении

- LICENSE (MIT для собственного исходного кода; подтвердить права на публикацию).
- THIRD_PARTY_NOTICES.md — список обязательных проверок лицензий сторонних моделей и бинарников.
- Отчёт Word с читабельными задачами и отметками редактора.
- Проверка лимита каждого файла релиза: <2 GiB, целостность ZIP, контрольные суммы SHA256.
- Дополнительная проверка архитектуры Apple Silicon и `hdiutil verify` в GitHub Actions.
- Инструкция для MacBook M4 и матрица поддерживаемых ОС.

## Что делать перед общедоступным релизом

1. Загрузить исходники через GitHub browser, сохранить `build.yml` отдельно через редактор (скрытая `.github` иногда не переносится браузером).
2. Дождаться зелёных **Windows-x64** и **Mac-Apple-Silicon** в Actions. Никаких скачиваний после красных сборок.
3. Запустить готовый EXE на реальной Windows и DMG на настоящем Mac M4, выполнить короткую офлайн-проверку, импорт DOCX/MP3, Word-отчёт, удаление проекта, паузу и продолжение.
4. Подписать и нотариализовать пакет macOS для максимально простой установки. Без Developer ID публикация возможна лишь как тестовая со штатными предупреждениями Gatekeeper.
5. Проверить точные лицензии скачанных checkpoint/FFmpeg/Qt и вложить notices в выпущенные артефакты.
6. Убедиться, что каждая вложенная ZIP/DMG **меньше 2 GiB**. Если пакет больше — не публиковать файл как Release, а заняться оптимизацией или разделением.
7. На GitHub открыть **Releases → Draft a new release**, tag `v0.8.0-beta.1` (при условии что этот тег ещё не занят), title `Audiobook QC 0.8 Beta — Windows x64 & macOS Apple Silicon`.
8. Прикрепить только два реально проверенных пакета и их отдельный файл `.sha256` для каждой платформы, отметить **Pre-release**. Не подменять бинарники исходниками. Сохранить как Draft до окончания ручных испытаний.
9. На главной странице README явно перечислить ограничения, особенно слабую проверку ударений, интонации и ложные срабатывания звуковых событий. Добавить ссылку на Releases.

## Предлагаемое описание релиза (скопировать в GitHub)

```
## Audiobook QC 0.8 Beta

Экспериментальное офлайн-приложение для проверки озвучки аудиокниг на соответствие рукописи.

- Word-отчёты по готовым частям, удобные таймкоды и отметки редактора.
- Whisper Medium + выборочная независимая проверка GigaAM.
- Предполагаемые кашель, звонки, щелчки, перегрузка, гул и шипение — только на прослушивание.
- Локальная обработка без платных API и без открытия браузера.
- Пакеты Windows x64 и macOS Apple Silicon (включая M4).

Важно: бета-версия; ложные и пропущенные предупреждения возможны. Интонация и ударения анализируются экспериментально. Перед исправлениями обязательно прослушайте звук.

На Mac неподписанная бета-версия может вызывать предупреждение Gatekeeper. Подробная инструкция находится в docs/Проверка-на-Mac-M4.md.
```
