# Публичная бета — один установщик для Windows, один DMG для Mac

GitHub репозиторий: https://github.com/kus142kus/AudiobookQC

## Загрузка нового исходного проекта

Распаковать `AQC-Source.zip` и через https://github.com/kus142kus/AudiobookQC/upload/main загрузить всё содержимое, сохраняя пути. **Особенно проверить `.github/workflows/build.yml`**. Содержимое файла должно иметь два jobs: `build` и `release`; шаг `Exercise actual Windows installer installation and removal BEFORE downloading models`. Сборка автоматически запустится после commit.

## Зелёная сборка — это ещё не публикация

Обычный commit **не** создаёт публичный релиз. На https://github.com/kus142kus/AudiobookQC/actions выбирается workflow `Audiobook QC 1.0 RC - offline release assets` → **Run workflow**. Только после того, как приняли решение о публичном бета-тестировании, выбрать параметр `publish_beta = true`. GitHub запускает обе сборки, проверяет файлы и после успеха публикует **Pre-release `v1.0.0-rc.1`**.

Проверить release https://github.com/kus142kus/AudiobookQC/releases . Для Windows нажать **только `AQC-Setup.exe`**, для Mac **`AudiobookQC-Mac.dmg`**. Windows-установщик сам скачает нужную модель `AQC-Model.zip`, проверит хэш и установит её. Модель не нужно скачивать отдельно и не нужно распаковывать два ZIP вручную. Установка Windows требует интернета **один раз**; работа приложения после неё — офлайн.

## Что подтвердить перед выпуском из бета-тестирования

- Фактическое открытие окна и 5–10 минут анализа на обычной Windows x64.
- Реальная установка DMG на папином M4 и проверка отчёта без интернета.
- Условия лицензий сторонних моделей и библиотек в `THIRD_PARTY_NOTICES.md`.
- Подпись Windows и Apple Developer ID + нотариализация Mac (если требуется простая установка без системных предупреждений).
- Отсутствие личных аудиозаписей и рукописей в GitHub.

Все тесты CI и даже зелёный GitHub Release не гарантируют, что нейросети точно выявляют все дефекты аудио. Испытания по размеченным дикторским ошибкам обязательны.
