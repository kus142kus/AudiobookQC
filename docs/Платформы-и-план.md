# Audiobook QC — поддерживаемые платформы и развитие

**Фактический статус на 25 ноября 2026 года.** Зелёная GitHub Actions сборка подтверждает прохождение автоматизированной сборки и CI-проверок, но не равна испытанию на каждом пользовательском компьютере.

| ОС / архитектура | Как собирается | Фактическая готовность | Публикация |
| --- | --- | --- | --- |
| Windows 10/11 x64, Intel/AMD | `.github/workflows/build.yml` — Inno Setup EXE + модель, загружаемая установщиком | GitHub Actions №38 успешно; приложение запускалось на Windows | Только тестовый RC до окончания проверки |
| macOS Apple Silicon arm64, включая M4 | Тот же workflow — DMG с моделями | GitHub Actions №38 успешно; реальный Mac M4 пока не проверен | Только тестовый RC до испытаний |
| Linux x64 | `.github/workflows/linux-preview.yml` — ручной запуск, `.tar.gz` при успехе | Экспериментальная, результат запуска пока не подтверждён | Не включать в основной релиз |
| Linux ARM64 | `.github/workflows/linux-arm64-preview.yml` — ручной запуск, `.tar.gz` при успехе | Экспериментальная, результат запуска пока не подтверждён | Не включать в основной релиз |
| Windows ARM64 | Нет нативного установщика | Требуется совместимость библиотек и аппаратное тестирование | Не публиковать как поддерживаемую |
| macOS Intel | Нет актуальной двухмодельной сборки | Необходимо найти совместимые версии/альтернативный ASR | Не публиковать как поддерживаемую |

## Как проверить Linux-сборки

В GitHub Actions слева выбрать **Audiobook QC - experimental Linux x64** либо **Audiobook QC - experimental Linux ARM64** → **Run workflow** → ветка `main` → **Run workflow**. Их сценарии **не** запускаются автоматически при обновлении обычного кода и **не** публикуются в Releases. При успешной работе появится отдельный артефакт PREVIEW; это ещё не проверенный удобный установщик Linux. После сборки нужен тест на реальном компьютере и отдельно решение по формату пакета (например, AppImage), в том числе по зависимостям Qt/FFmpeg.

## Критерии перехода к стабильной версии 1.0

1. Windows x64 и Mac Apple Silicon: успешная установка из **опубликованных** релизов, а не только из GitHub Actions.
2. Mac M4: окно запускается и формирует Word-отчёт после офлайн-анализа реального фрагмента.
3. Измерены precision/recall на размеченном наборе примеров; разработчик явно описывает долю пропусков и ложных тревог.
4. Длинная запись: пауза, продолжение, отчёты по частям и итоговый Word без потери данных.
5. Завершён аудит лицензий моделей/библиотек, соблюдены условия распространения; публичная Mac-подпись/нотаризация отдельно рассмотрена.
6. Для каждой дополнительно заявленной ОС есть собственная реально проверенная сборка. Нельзя называть приложение «для всех ОС» только по наличию зелёных тестов исходников.
