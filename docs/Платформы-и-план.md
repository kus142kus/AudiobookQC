# Поддерживаемые платформы и цели

Все процессы распознавания офлайн и ориентированы на 64-битные архитектуры. «Все ОС» не означает любые процессоры и версии системы без тестов. Нельзя создавать неподтверждённые ссылки на скачивание.

| Система | Что есть сейчас | Статус для релиза |
| --- | --- | --- |
| Windows 10/11 x64 (Intel/AMD) | Автоматическая сборка EXE + запуск GUI/трёх моделей | Бета-кандидат: требуется проверка на реальном ПК |
| macOS Apple Silicon M1/M2/M3/M4/M5 | Автоматическая сборка DMG на arm64 + запуск GUI/трёх моделей + аудит Mach-O | Бета-кандидат: требуется пробный запуск на M4, подпись/нотаризация для массовой установки |
| Linux x64 | Экспериментальный CI preflight Qt + нативный GUI; полноценная офлайн-сборка — отдельная задача | **Не публиковать как поддерживаемую**, пока не пройдёт полный frozen smoke и реальный Linux-тест |
| macOS Intel x86_64 | Нет актуальной двухмодельной сборки | Требуется отдельная матрица устаревшего PyTorch/альтернативного ASR; PyTorch 2.8 не поставляет обычные колёса macOS Intel |
| Windows ARM64 | Отдельной сборки нет | Требуется проверка Torch/Qt/ONNX для Windows ARM, затем реальный запуск на оборудовании |
| Linux ARM64 | Отдельной сборки нет | Зависит от доступности всех wheel и аппаратного тестирования |

Разработка Linux x64: `.github/workflows/compatibility.yml`. После успешной сборки и реального испытания можно включить в основной релиз.

Приоритеты: **1. Windows x64 + macOS arm64; 2. Linux x64; 3. Windows ARM64 и Mac Intel в отдельном совместимом режиме.**

Дополнительно перед релизом:

- Сборка из чистого checkout, фиксированные зависимости, без сетевого обращения при запуске.
- Подписанный DMG/нотаризация для массовой дистрибуции macOS. Нельзя утверждать, что неподписанный DMG устанавливается «как обычное приложение» без системных предупреждений.
- Модели и сторонние зависимости должны иметь корректные лицензии и уведомления.
- Артефакты должны быть **меньше 2 GiB каждый**, проверены на целостность; публикация только успешной проверенной сборки.
- Публичные примеры не должны содержать приватные рукописи и аудио.
