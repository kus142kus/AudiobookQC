# Audiobook QC 1.0 RC — ограниченный тестовый выпуск

Локальная проверка аудиокниг по рукописи: Whisper Medium, независимая перепроверка GigaAM, предполагаемые посторонние звуки через YAMNet, промежуточные Word-отчёты, абсолютные таймкоды и продолжение многочасовых проверок.

## Установка

**Windows 10/11 x64:** скачайте только **`AQC-Setup.exe`** и запустите. Установщик самостоятельно скачает официально опубликованный вместе с этой версией архив Whisper (`AQC-Model.zip`), проверит SHA-256, установит все файлы и проверит комплект. *Нужен интернет во время первоначальной установки*, после неё аудио обрабатывается полностью локально, без браузера и платных API. Не нужно вручную скачивать, объединять или распаковывать ZIP.

**Mac на Apple Silicon (M1/M2/M3/M4/M5):** скачайте **`AudiobookQC-Mac.dmg`**. В нём программа с моделями уже включена. Откройте DMG, перенесите приложение в Applications, запустите. Публичный билд без Developer ID/Apple notarization может вызвать предупреждение Gatekeeper. Не отключайте системную защиту ради установки; используйте штатный механизм разрешения приложений от идентифицированного источника по инструкции Apple.

Модель `AQC-Model.zip` опубликована **для работы автоматического Windows-установщика**. Обычным пользователям скачивать её отдельно не требуется.

## Ограничения

Это релиз-кандидат, не сертифицированный стабильный выпуск. Испытания на Mac M4 и независимая оценка распознавания по размеченным записям ещё обязательны. Распознавание может ошибаться, звуковые события — давать ложные срабатывания, ударения и интонация проверяются экспериментально. Каждое найденное место необходимо прослушивать. Шестичасовые книги обрабатываются частями; скорость зависит от памяти и CPU. Intel Mac, Windows ARM64 и Linux пока не обозначаются как проверенные установочные пакеты.

Дистрибутивы собираются с открытыми/сторонними библиотеками; перед стабильным релизом необходимо дополнительно проверить лицензии, подпись Windows и нотариализацию Mac. Аудио и рукописи не передаются на серверы программы.
