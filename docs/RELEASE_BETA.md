# Audiobook QC 1.0 RC2 — предварительный выпуск для Windows и Mac Apple Silicon

**Audiobook QC** помогает проверять запись аудиокниги по оригинальному тексту и создавать Word-отчёты с таймкодами. Приложение работает локально: пользователю не нужны подписка, платный API или облачный сервис.

## Возможности

- Сопоставление русскоязычной озвучки с DOCX/TXT: предполагаемые оговорки, пропуски, замены слов, повторы.
- Две независимые локальные модели распознавания: Whisper Medium и выборочная перепроверка GigaAM.
- Отдельный список менее уверенных находок — важные ошибки не нужно смешивать с мелкими сомнениями.
- Прослушивание подозрительных фрагментов прямо в программе; отметки «Исправлено» и «Не ошибка».
- Word-отчёты с таймкодами по готовым частям и итоговый отчёт по окончании книги.
- Дополнительные **неподтверждённые** предупреждения о возможных звуковых дефектах.

## Установка

**Windows 10/11 x64:** скачайте **только `AQC-Setup.exe`**. На первой установке EXE автоматически скачает и проверит модель `AQC-Model.zip`, опубликованную вместе с ним; этот ZIP **не нужно скачивать вручную**. Интернет нужен для установки модели, но **не для обработки аудио после установки**.

**macOS Apple Silicon (включая M4):** скачайте **только `AudiobookQC-Mac.dmg`**, перенесите приложение в **Программы**. Модели включены. Неподписанный/ненотариализованный выпуск может вызвать предупреждение безопасности macOS; не отключайте защиту системы глобально.

**Другие платформы:** Linux x64/ARM64 — экспериментальные отдельные сборки, не входят в этот релиз; Windows ARM64 и macOS Intel — пока не поддерживаются.
