## Как обновить без командной строки

1. Установи бесплатный **GitHub Desktop**: https://desktop.github.com/ . Авторизуйся в своём аккаунте GitHub.
2. В GitHub Desktop выбери **File → Clone repository**, найди `kus142kus/AudiobookQC` и клонируй в отдельную папку на компьютере.
3. В приложении нажми **Repository → Show in Explorer** («Открыть в проводнике»). Не удаляй текущие файлы.
4. Распакуй этот ZIP. Скопируй **всё его содержимое** (папки `.github`, `docs`, `installer`, `scripts`, `tests` и файлы в корне) в папку клонированного репозитория, согласись на замену одноимённых файлов.
5. В GitHub Desktop проверь список изменений; внизу введи краткое название коммита, например `Fix installer tests and release workflow`, и нажми **Commit to main → Push origin**.
6. На https://github.com/kus142kus/AudiobookQC/actions посмотри два задания (**Windows-x64**, **Mac-Apple-Silicon**). При ошибке открой красное задание и скопируй последние строки первого упавшего шага.
7. **Не включай `publish_beta`**, пока все тесты и проверки реально не пройдут и не протестированы исходные аудиозаписи. Публикация общедоступной беты — отдельное действие.

## Оговорки

- На этой системе нельзя нативно запускать Windows EXE и Mac DMG или проверить папин Mac M4.
- Архив не содержит гигабайтных нейросетей и всего исходного проекта. Реальную точность поиска ошибок здесь не измеряли.
- Mac DMG с полными моделями может превысить лимит **2 GiB на один файл GitHub Release**. Это пока риск, который должен быть измерен после полноценной сборки; не надо объявлять пакет готовым заранее.
- Не загружай реальные аудиокниги, их рукописи, отчёты и личные данные в открытый GitHub.
