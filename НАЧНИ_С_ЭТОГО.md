# Кириллу: AudiobookQC — обновление на пути к версии 1.0

**Это не готовая программа и не выпущенная версия 1.0.**
Это дополнительный исправляющий патч к уже существующему GitHub-проекту
`kus142kus/AudiobookQC`: он не содержит полный `src/`, `run.py`, папку `models/`,
исполняемые файлы Windows или Mac.

## Что я сделал (на 24.11.2026)

- Сохранил исходное обновление Windows-установщика и исправления его тестов.
- Устранил опасную последовательность проверки публикации: раньше скрипт **перезаписывал**
  проверочные SHA-256-файлы прямо перед сравнением. Добавил режим `--verify`,
  который сравнивает исходные контрольные суммы и не изменяет их.
- Добавил отказ от подозрительных путей, дублированных ZIP-элементов и симлинков
  в релизном архиве модели.
- Добавил защиту от удаления готового приложения при неверном пути временной
  папки сборщика установщика.
- Добавил проверку, что Windows-установщик ссылается на ту же версию релиза,
  что и GitHub Actions.
- Добавил **отдельный инструмент объективной оценки**: считает найденные,
  пропущенные, ложные срабатывания с контролем дублей и проверкой таймкодов
  свыше шести часов; создаёт Word-отчёт и JSON с итогами. Он пока **не встроен
  в пользовательский интерфейс**.
- Добавил синтетический пример разметки и автоматические регрессионные тесты.

## Что протестировано

На доступном Linux/Python: **27 из 27** доступных тестов патча прошли,
компиляция Python-файлов успешна, YAML-синтаксис проверен, синтетическая
упаковка модели и согласованность тега релиза проверены. Это **не означает**,
что все примерно 135 тестов основного проекта, реальное распознавание,
Windows-установщик и DMG на Mac прошли проверку.

## Самый простой шаг, чтобы я мог довести проект дальше

**Лучше сначала получить полную копию GitHub-репозитория.**

1. Открой https://github.com/kus142kus/AudiobookQC
2. Нажми зелёную кнопку **Code** → **Download ZIP**.
3. Отправь этот ZIP в наш чат. Не нужно объединять папки, писать команды и
   вручную удалять что-либо из проекта.
4. Если GitHub предлагает подключение к ChatGPT, можно использовать его для
   чтения файлов и действий в репозитории при наличии разрешения.

Затем уже можно будет в одном наборе исходников проверить `dual_engine.py`,
`analysis.py`, `worker.py`, `report.py`, `run.py`, интерфейс и CI, интегрировать
проверку качества, устранить обнаруженные несовместимости и собирать
запускаемые версии под Windows и Mac M4.

## Если хочешь наложить этот патч самостоятельно

В GitHub Desktop (https://desktop.github.com) выбери File → Clone repository,
открой папку проекта и **скопируй всё содержимое** распакованного этого ZIP в
корень клонированного проекта. Подтверди замену одноимённых файлов; остальные
файлы НЕ УДАЛЯЙ. В GitHub Desktop: Commit → Push. На сайте GitHub открой
Actions и проверь обе системы. **Не включай publish_beta**, пока не проверены
реальные дистрибутивы, качество на тестовых записях и права на модели.
