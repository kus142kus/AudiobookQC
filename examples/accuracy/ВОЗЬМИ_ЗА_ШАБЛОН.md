# Образец разметки проверки (ВЫМЫШЛЕННЫЕ данные)

Эти примеры **не являются записью папы и не доказывают качество приложения**.

- `truth.csv` — только ошибки, заранее подтверждённые прослушиванием;
- `findings.csv` — замечания AudiobookQC. В `importance=high` помещать **только существенные** исправления, действительно находящиеся в главном разделе отчёта; `review`/`minor` по умолчанию исключаются.
- Если источник результата — Word, сначала извлечь кандидатов через `--extract-docx`; результат специально имеет `importance=review`, потому что по структуре документа нельзя доказать, что каждое место подтверждено двумя моделями и что это серьёзная ошибка.

Команда из корня репозитория (для разработчика):

```bash
python scripts/benchmark_readings.py --truth examples/accuracy/truth.csv \
  --findings examples/accuracy/findings.csv \
  --output accuracy-example.json --docx accuracy-example.docx \
  --duration-hours 0.25 --tolerance 5
```

Это демонстрационный пример. Проверка на реальных материалах проводится только локально, **не отправляй текст и аудио в публичный репозиторий**.
