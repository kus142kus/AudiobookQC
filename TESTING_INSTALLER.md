# Новый процесс установки — тот же, что в публичном релизе

**Обычный пользователь Windows скачивает только `AQC-Setup.exe`.** Не нужно распаковывать, объединять или перемещать какие-либо ZIP. Установщик автоматически загружает Whisper с этой же версии GitHub Release, проверяет SHA-256, копирует в правильную папку, затем запускает автономную самопроверку. При обновлении он переиспользует совпадающую модель. Интернет необходим только при первой установке, после этого Audiobook QC работает без подключения.

**MacBook M4:** обычный пользователь скачивает только `AudiobookQC-Mac.dmg`, открывает и перетаскивает `AudiobookQC.app` на значок `Applications`. Три модели уже включены в DMG.

## Обновление источников через браузер (без Git/GitHub Desktop)

1. Распакуйте `AQC-Update.zip` — это *исходники для обновления репозитория*, а не приложение.
2. Откройте https://github.com/kus142kus/AudiobookQC/upload/main . Загрузите содержимое, сохраняя пути файлов.
3. Особое внимание — `.github/workflows/build.yml`. Если он не заменился, обновите его отдельно через https://github.com/kus142kus/AudiobookQC/edit/main/.github/workflows/build.yml . В конце файла должен быть job `release` с шагом `Publish GitHub public prerelease with direct EXE and DMG links`.
4. Откройте https://github.com/kus142kus/AudiobookQC/actions . Обычный commit проверяет сборки, но пока ничего не публикует.
5. Чтобы получить **настоящий тестовый установщик по публичной ссылке**, откройте workflow `Audiobook QC 1.0 RC - offline release assets` → `Run workflow` → поставьте `publish_beta = true` и запустите. После успешной сборки автоматически будет создан **Pre-release** `v1.0.0-rc.2` с тремя файлами.
6. Откройте https://github.com/kus142kus/AudiobookQC/releases и скачайте `AQC-Setup.exe`. **Не скачивайте Actions Artifacts. Не загружайте модель вручную.** Это будет тот же способ, что у всех пользователей.

## Проверки и ограничения

В этом пакете отдельно проверены **4 теста установщика**, синтаксис Python и синтетическая реконструкция модельного ZIP; файл workflow разбирается YAML-парсером. Полный набор тестов исходного репозитория и реальная сборка на Windows/macOS здесь **не выполнялись**. В GitHub Actions добавлена ранняя установка/удаление тестового Inno Setup до скачивания нейросетей. Полная проверка должна пройти после загрузки архива в репозиторий.

**Не подтверждено в текущей среде:** реальная компиляция Inno в Windows runner и первый запуск нового EXE, а также открытие DMG на настоящем M4. CI на GitHub должен выполнить эти этапы прежде чем получится выпуск. Предрелиз неподписанный; Windows SmartScreen и macOS Gatekeeper могут выдавать штатные предупреждения. Публичный выпуск требует отдельного решения владельца проекта, аудита сторонних лицензий и проверки качества на реальных записях.
